## Verifikasi pilihan stack

Halaman karier resmi https://stamps.id/en/careers/ menyebut pada Back-end Engineer:

- Bahasa server dengan **Python preferred**.
- Database relasional seperti **PostgreSQL**.
- Nilai tambah **Python dan Django**, **Redis**, Docker atau Ansible.
- Linux, AWS, keamanan, API, efisiensi query, pengujian, dan code review turut disebut.

Halaman ini membahas posisi Back-end Engineer, bukan salinan persis posisi junior Glints. Namun, lebih kuat sebagai bukti relevansi Django daripada menebak teknologi dari tampilan situs. Langganin memilih Django/PostgreSQL/Redis, tidak mengklaim identik dengan arsitektur internal Stamps.

## Mengapa Langganin

Satu alur utuh pelanggan → pembelian → poin → reward → kampanye → dashboard paling langsung menunjukkan pemahaman domain CRM/loyalty. Penguncian baris, transaksi atomik, UUID idempotensi, consent, dan pengujian paralel relevan untuk ketepatan sistem yang dipakai bersamaan.

Desain dan nama orisinal. Tidak mengambil logo, screenshot produk, data pelanggan, atau kode tertutup Stamps. Tidak menjalankan scraping terjadwal, pendaftaran, pengiriman lamaran, atau menghubungi rekruter. Riset tidak menjamin lolos seleksi.
